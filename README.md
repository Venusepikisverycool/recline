# Recline

Recline adds a way to relax in beds during the daytime without forcing the player to sleep.

Instead of skipping time, players can recline in a bed and leave whenever they want, while keeping normal nighttime sleeping behavior.

## Features

- Recline in beds during the day
- Keeps normal nighttime sleep functionality
- Allows leaving the bed normally
- Removes the default sleeping fade effect

## Requirements

- Minecraft 1.21.1
- Fabric Loader
- Fabric API

## Installation

1. Install Fabric Loader for Minecraft 1.21.1.
2. Install Fabric API.
3. Place the Recline `.jar` file into your Minecraft `mods` folder.
4. Launch Minecraft.

## Usage

Simply right-click a bed during the day to recline.

At night, beds work normally and will skip the night like vanilla Minecraft.

## Compatibility

Recline modifies Minecraft's bed and sleeping behavior, so compatibility with other mods that heavily change sleeping mechanics may vary.
